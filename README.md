Typed `ghbdtn` when you meant `привет`? Press **Pause**: Keyboard Gobloon retypes the last word in the
next layout and switches the layout for you. Press it again to go back.

It runs in the tray, uses about 2 MB of memory and no CPU while you're not typing, and never sends or
stores what you type.

## Coming next

- Automatic layout switching while you type, English and Russian first, more languages as downloads.
- Automatic typo correction.
- A local AI that turns a rough prompt into a better one for Claude, ChatGPT or Gemini.

## Getting started

Windows 10 / 11 (x64): download the installer or the portable zip from the
[latest release](https://github.com/h0useRus/KeyboardGobloon/releases/latest). The installer needs no
administrator rights.

Builds are not code-signed yet, so Windows SmartScreen may warn on the first start:
*More info → Run anyway*.

> **Status:** early alpha.

Keyboard Gobloon is free, with no ads and no tracking. If it saves you time, a
[donation](https://www.paypal.com/paypalme/h0userus) helps keep it going.
